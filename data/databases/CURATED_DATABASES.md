# Curated PROBEAT databases

The small curated tables distributed with PROBEAT are interpretation layers,
not evidence of experimentally demonstrated probiotic activity.

| File | Version | Purpose | Provenance status |
|---|---:|---|---|
| `PGMDB.tab` | 2026-06 | Probiotic gene marker matching | Needs per-row source and license audit before public release |
| `gut_brain_axis_marker_database.tsv` | 2026-06 | Gut-brain metabolite and trait markers | Needs per-row source and license audit before public release |
| `probiotic_cazy.txt` | 2026-06 | Prebiotic carbohydrate utilization interpretation | Needs per-row source and license audit before public release |

Before a public release, each row must have a traceable source, citation, and
license-compatible provenance. Changes must be recorded in `CHANGELOG.md`.
